# Identidade Visual - Grupo Arqueo

## Cores Principais (baseado no site grupoarqueo.com.br)

### Paleta de Cores
- **Bordô/Vinho**: #8B1538 (cor principal/primária)
- **Laranja**: #E85D04 (destaque/ação)
- **Azul**: #1E3A5F (profissional/confiança)
- **Amarelo**: #F9A825 (alertas/destaques)

### Cores Complementares
- **Branco**: #FFFFFF (fundos)
- **Cinza Claro**: #F5F5F5 (backgrounds alternativos)
- **Cinza Escuro**: #333333 (textos)

## Aplicação no Sistema
- **Primary**: Bordô #8B1538 - botões principais, links, sidebar ativa
- **Secondary**: Azul #1E3A5F - elementos secundários, cabeçalhos
- **Accent**: Laranja #E85D04 - CTAs, destaques importantes
- **Warning**: Amarelo #F9A825 - alertas, avisos
- **Destructive**: Vermelho #DC2626 - erros, ações destrutivas
- **Success**: Verde #16A34A - sucesso, confirmações

## Tipografia
- Fonte principal: Inter (sans-serif)
- Títulos: Semi-bold/Bold
- Corpo: Regular
